Native Windows x64 preview of Scorched Everitt. Extract the ZIP and run ScorchedEveritt.exe with its picts folder.

Original menus, six tank sets, terrain atlas, bitmap font and all 24 intro frames are included. Source-derived ballistics, collision, turn/round scoring, upgrades and PIT-derived audio are translated to C++/Win32.

This is a preservation preview, not certified 1:1 parity. Windows native CI tests are not an interactive Windows 11 playthrough. See docs/PARITY.md for source quirks and known timing/rendering differences; NOTICE.md explains attribution and the absence of an upstream license. Unsigned binary.
